# Sources & References

This project cites authoritative references for accessibility, usability, and web standards. These sources informed design and implementation decisions.

## Accessibility & ARIA
- W3C Web Content Accessibility Guidelines (WCAG) 2.2
  https://www.w3.org/TR/WCAG22/
- WAI-ARIA Authoring Practices Guide (APG)
  https://www.w3.org/WAI/ARIA/apg/
- MDN Web Docs — Accessibility overview
  https://developer.mozilla.org/en-US/docs/Web/Accessibility

## Usability & UX
- Nielsen Norman Group — 10 Usability Heuristics
  https://www.nngroup.com/articles/ten-usability-heuristics/
- Google Material Design — Accessibility overview
  https://m3.material.io/foundations/accessible-design/overview

## Web Standards
- WHATWG HTML Living Standard
  https://html.spec.whatwg.org/
- MDN Web Docs — HTML forms and input elements
  https://developer.mozilla.org/en-US/docs/Learn/Forms

## Security & Best Practices (backend guidance)
- OWASP Secure Coding Practices (general guidance)
  https://owasp.org/www-project-secure-coding-practices-quick-reference-guide/
